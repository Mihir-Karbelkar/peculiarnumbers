# Peculiar Numbers

A static Astro mathematics laboratory for exploring unusual integer patterns.

## Development

```sh
bun install
bun run dev
```

## Cloudflare Pages

This project is configured for Cloudflare Pages as a static Astro site.

- Build command: `npm run build` or `bun run build`
- Build output directory: `dist`
- Node version: `22.16.0`

The Cloudflare Pages output directory is also recorded in `wrangler.toml` via `pages_build_output_dir = "dist"`.
